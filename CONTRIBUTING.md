# Como contribuir

1. Escolha um item do [ROADMAP.md](ROADMAP.md) ou abra uma *issue* descrevendo a ideia.
2. Leia o [CLAUDE.md](CLAUDE.md): ele resume as regras do projeto.
3. Rode `npm test` antes de enviar. Se mexer no `parser.js`, inclua um caso de teste com o texto real do print.
4. Teste no navegador com tela de celular.
5. Commits em português, no imperativo e curtos ("Adiciona foto no jogo").
